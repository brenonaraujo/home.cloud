# ADR-0001 — i18n en + pt only

**Status:** accepted  
**Date:** 2026-08-30  
**Context:** git-meta-harness invariante 11 exige `en`, `pt-BR`, `es`. O console e o site Brenon já operam `en` + `pt` (vue-i18n). Não há mercado es neste produto.

**Decision:** idiomas obrigatórios = `en` e `pt`. Sensor 08 neste repo verifica paridade dessas duas chaves. Não adicionar `es` vazio “para o harness”.

**Consequences:** PRs que introduzam copy só em um idioma falham QA. PRs que exijam `es` são recusados. Revisitar se BRNN tiver audiência hispânica.
